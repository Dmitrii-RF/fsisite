# StopPhishing — информационный сайт грантового проекта

Адаптивный одностраничный сайт без сборки и внешнего JavaScript. Можно разместить на GitHub Pages бесплатно.

## Публикация

1. Создайте публичный репозиторий GitHub с названием `stopphishing` или `<username>.github.io`.
2. Добавьте в корень репозитория `index.html` и папку `assets`.
3. В репозитории откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем сохраните.
5. Адрес будет `https://<username>.github.io/stopphishing/` (или `https://<username>.github.io/` для второго типа репозитория).

## Обязательно перед официальной публикацией

- В папке `assets` уже размещены два официальных логотипа: `logo_FSI.png` и `logo_PUTP.png`.
- Сверьте формулировку и перечень логотипов с грантовым договором и актуальным брендбуком.
- Проверьте юридическое название `ООО «СВ»` и контактный email.
- Обновите блок «Основные направления разработки» реальными достигнутыми результатами, если они необходимы для отчётности.
- Демонстрационная карточка браузера — **не подключённое расширение** и **не фактический результат ML-модели**.
- Google Fonts требует сетевого доступа. Для полностью автономного шрифта можно заменить Manrope системным.

## Как изменить текст

Весь контент расположен в `index.html`. Никакие npm-пакеты или сборка не нужны.
