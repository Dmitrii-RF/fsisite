О проекте

Новая технология для безопасного веб-сёрфинга

Цель проекта — разработка браузерного расширения на основе искусственного интеллекта для Google Chrome, предназначенного для автоматического выявления фишинговых сайтов и защиты пользователей от онлайн-мошенничества.

Официальное наименование работ: «Создание расширения браузера для автоматического выявления фишинговых сайтов и повышения кибербезопасности пользователей».

01

Актуальная задача

Фишинговые сайты могут имитировать знакомые сервисы, чтобы обманом получать конфиденциальные данные пользователей.

02

Автоматизированная проверка

Проверка открываемого веб-ресурса инициируется браузерным расширением.

03

Интеллектуальный анализ

Серверная часть использует модель машинного обучения для оценки признаков возможного фишинга.

Принцип работы

От перехода на сайт до результата анализа

Система состоит из браузерного расширения и серверной части с ML-моделью. При посещении веб-ресурса расширение направляет запрос на проверку и получает ответ.

ШАГ 01

Переход на сайт

Пользователь открывает веб-страницу в Google Chrome.

ШАГ 02

Запрос к серверу

Расширение передаёт данные, необходимые для анализа ресурса, серверной части.

ШАГ 03

ML-анализ

Модель машинного обучения оценивает ресурс на наличие признаков фишинга.

ШАГ 04

Ответ расширению

Сервер возвращает результат, который расширение может показать пользователю.

Технологии

Современный подход к выявлению фишинга

В основе решения — взаимодействие браузерного расширения с серверным сервисом анализа на базе машинного обучения.

Раздел описывает принципиальную архитектуру проекта без раскрытия внутренних деталей реализации.

Машинное обучение

Автоматизированная оценка признаков фишинговых веб-ресурсов.

Браузерное расширение

Интеграция механизма проверки в среду Google Chrome.

Серверная обработка

Обработка запросов и возврат результата анализа расширению.

Обмен через API

Связь между клиентским расширением и backend-компонентом.

Реализация

Основные направления разработки

Проект направлен на создание комплексного решения, объединяющего пользовательский компонент и систему интеллектуального анализа.

◈

Расширение для Chrome

Разработка программного компонента, взаимодействующего с открываемыми пользователем веб-страницами.

⌘

Backend-сервис

Организация серверной обработки запросов и обмена результатами с браузерным расширением.

◎

ML-модель

Применение методов машинного обучения для анализа и выявления потенциально фишинговых сайтов.
